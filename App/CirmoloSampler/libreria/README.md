# Stock sample library

These samples come from the sample library shipped with the official release 1.5.0 of
LittleGPTracker (djdiskmachine/LittleGPTracker, GPLv3; see LICENSE in this folder). Cirmolo
included that tracker until October 2026; when it was replaced by Fioritura the library moved
here, where Cirmolo Sampler shows it as "Libreria di serie". Pads saved with the old path
(`App/LittleGPTracker/samplelib/...`) are moved to this folder automatically when the state loads.
