# Sito di Cirmolo

Ramo `gh-pages` del progetto [Cirmolo](https://github.com/luigismith/cirmolo): le pagine pubblicate su
https://luigismith.github.io/cirmolo/ (home, pagine delle app e manuale illustrato di OpenOrc in `openorc/`).

Il sito ha l'aspetto del tema STAME, quello di serie della console: il tema Giorno di
[Stame](https://luigismith.github.io/stame/), un LCD riflettente. La base comune è `stame.css` (colori,
caratteri, barra, bottoni, schermi); le pagine delle app aggiungono `app.css`, le altre il loro stile.
I caratteri in `fonts/` (Matrice e Spleen, con le licenze), la pigna a inchiostro, il marchio di Stame,
`favicon.png`, l'anteprima per i link e le schermate del tema in `img/` li scrive
`.github/branding/sito_stame.py`, sul ramo `cirmolo`.
Le schermate delle app sono generate con il codice delle app, identiche a quelle della console.
